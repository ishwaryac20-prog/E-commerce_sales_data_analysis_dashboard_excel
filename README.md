# 📊 E-Commerce Sales Dashboard Analysis

A structured Excel-based project designed to analyze sales performance, identify business trends, and generate actionable insights through interactive dashboards and data visualization.

---

## 📖 Overview

This project analyzes sales data to understand business performance, customer behavior, and revenue trends. Using Microsoft Excel, the dataset was cleaned, transformed, and analyzed to uncover meaningful insights across product categories, regions, payment methods, store types, and yearly sales performance.

The project demonstrates practical skills in data analysis, reporting, dashboard development, and business intelligence.

---

## 🎯 Business Problem

Organizations generate large volumes of sales data every day. Without proper analysis, it becomes difficult to identify growth opportunities, understand customer behavior, and make informed business decisions.

This project aims to transform raw sales data into actionable insights that support strategic planning and business growth.

## 🆘 Help

### Dashboard Not Updating

**Solution:**
- Go to Data → Refresh All.
- Verify Pivot Tables are connected to the correct dataset.
- Check slicer connections.

### Charts Not Displaying Properly

**Solution:**
- Refresh Pivot Charts.
- Ensure source data is available.
- Verify chart ranges are correct.

### Filters Not Working

**Solution:**
- Check slicer connections.
- Clear all filters and reapply selections.
- Refresh the workbook.
